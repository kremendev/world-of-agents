# v3.6.0 desktop check

For Dima, before the `v3.6.0` tag, and after v3.5.0's check and tag. Only what needs you: the desktop app, the page next
to your mockup, Narrator and two small real runs. Everything else was proven without you (docs/v3.6-plan.md, each part's
notes; the Team page in Edge on a throwaway hall, keyboard only). Each step says what you should see and which part it
proves. Anything that doesn't match: stop there and note the step number.

## Before you start

1. In the repo: `git switch --detach 377bfbb`, then `npm run dev:refresh`. Stop any hall on 4319 (in PowerShell:
   `Get-NetTCPConnection -LocalPort 4319 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess }`).
   Close all other sessions. Open `woa-m2-test` in the Code tab, one new session, Manual, `/reload-plugins`.

## The refresh (3.6d)

2. Open a new session and type **hi**. Your team was written by v3.5.0, so the pane says "Your team's specialist files
   are from an older plugin. Type /world-of-agents:setup-team-write to refresh them."
3. Type `/world-of-agents:setup-team-write`. It says "Refreshed the team's files for this plugin: 8 specialists and 14
   skills, each as it was." (more if you added any), and lists them. Open a new session: the line from step 2 is gone.

## The Team page (3.6c)

4. Press **Open Team page** in the pane (it was **Change skills**) and open the link. The Team page opens straight away. Put it next to your
   mockup's page 2: the top bar (Back to the hall, World of Agents / Team, the search box), "Team" and its intro line,
   the Specialists and Skills tabs with 8 and 14, the list by guild on the left, the React designer on the right with
   its switch, What it may do, its skills as chips, + Add skill, Model, Started by, Its id, Change and Delete. No pixel
   font anywhere on this page. Note whatever differs from the mockup.
5. Make the window narrow, about a phone's width: the list goes above the details, nothing scrolls sideways.
6. **Back to the hall**: the hall view as you left it, still Live, no "Hall offline", the feed as it was.

## Keyboard and Narrator (3.6c)

7. Press **Team** in the header: the Team page again, with the same session, no new link needed. Turn Narrator on.
   Tab through: Back to the hall, the search, the Specialists tab (read as a selected tab), + Add specialist, the
   specialists, then the switch, read as "React designer, switch, on" or close to it. Press Space: Narrator reads
   "Switched React designer off." Press Space again to switch it on.
8. Tab to the **×** after Accessibility and press Enter: Narrator reads "Took Accessibility from React designer.", and
   the focus is on + Add skill. Shift+Tab back to **Undo** in the status line and press Enter: Accessibility is back in its place, between React UI patterns and Design tokens (3.6e).
9. Type **test** in the search: Specialists 2 and Skills 2, the Test writer shown, as on your mockup's page 5. Clear it
