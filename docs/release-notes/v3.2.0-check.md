For Dima, before the `v3.2.0` tag, after v3.1.0's checklist passed. Each step says what you should see and which part of
docs/v3.2-plan.md it proves. Anything that doesn't match: stop there and note the step number.

1. In the repo, on `v3-next` at the v3.2.0 commit: `npm run dev:refresh`, then stop any hall on 4319 (v3.1.0's checklist,
   step 2), open `~/Downloads/woa-m2-test` in the desktop app's Code tab, start a new session, Manual, `/reload-plugins`.

## The pane (3.2a)

2. Before the first answer the pane's Usage block says "This PC: nothing counted yet." (On a PC where an earlier session
   already counted, it shows that total instead.)
3. Type: **Have the Reviewer review hello.js for bugs.** When the Lead answers, the Usage block has a line "This PC since
   <today>: …K tokens in, …K out, about $… at API prices (11 Nov 2026)." Both the Lead's and the Reviewer's turns count.
4. Open claude.ai/settings/usage in the browser. The pane's 5-hour and weekly percentages match it within a point or two
   (milestone 3's "done when"; they come from the engine, refreshed on each measure).
5. `/reload-plugins`: the "This PC" line comes back with the same total. Close the app, open it again, a new session: the
   same total (it is kept in the plugin's store).

8. Reload the hall page: the line is back at once (the hall keeps the last total in memory).
