# v3.2.0 desktop check

For Dima, before the `v3.2.0` tag, after v3.1.0's checklist passed. Each step says what you should see and which part of
docs/v3.2-plan.md it proves. Anything that doesn't match: stop there and note the step number.

## Before you start

1. In the repo, on `v3-next` at the v3.2.0 commit: `npm run dev:refresh`, then stop any hall on 4319 (v3.1.0's checklist,
   step 2), open `~/Downloads/woa-m2-test` in the desktop app's Code tab, start a new session, Manual, `/reload-plugins`.
   A ledger from before 3.2d (13 Nov) reads as nothing (L16): the pane starts again from "nothing counted yet".

## The pane (3.2a, 3.2d)

2. In the team pane, under **Usage**: "This PC: nothing counted yet.", then "Only World of Agents sessions so far. Press
   Recount to include everything.", a **Recount** button, and "Recount reads only the token counts in Claude Code's
   transcripts on this PC, when you press it." (On a PC where a session already counted, the first line shows that
   total instead.)
3. Type: **Have the Reviewer review hello.js for bugs.** When the Lead answers, the Usage block has a line "This PC since
   <today>: …K tokens in, …K out, about $… at API prices (13 Nov 2026)." Both the Lead's and the Reviewer's turns count.
4. Open claude.ai/settings/usage in the browser. The pane's 5-hour and weekly percentages match it within a point or two
   (milestone 3's "done when"; they come from the engine, refreshed on each measure).
5. `/reload-plugins`: the "This PC" line comes back with the same total. Close the app, open it again, a new session: the
   same total (it is kept in the plugin's store).

## The hall's page (3.2b, 3.2d)

6. Right after step 5's new session, before you type anything: "Open hall" in the pane. The badge at the top left says
   "Forge Hall · v3.2.0", and the header, beside "Tasks done", says "This PC: … tokens · about $… at API prices", the
   same total as the pane (in and out added), at once: the pane started this hall, and it gets the total as soon as it
   answers (L10, the step that failed on 13 Nov). It updates after the Lead's next answer.
7. "Play demo": the line goes (the demo has no ledger). "Back to live": it is back.
8. Reload the hall page: the line is back at once (the hall keeps the last total in memory).

## Another install's hall (3.2d, L11)

9. Close the app. Open it, and first start a session in `~/Downloads/woa-test` (v3.0.1 from GitHub): its pane starts its
   own hall. Then start a new session in `~/Downloads/woa-m2-test`. Its pane says "An older hall (before v3.2.0) is
   running. Close the sessions in your other projects." in yellow, with no "Open hall" link. Close the `woa-test` session,
   then send any message in `woa-m2-test`: the pane says "Hall: running" with the link again, and the hall's header shows
   the total.

## Recount (3.2c, 3.2d)

10. In the team pane, under Usage, below the "This PC" line, press **Recount**. "Recounting..." shows for a few seconds.
    Then the "This PC" line starts at the date of your oldest transcript, and the line under it says "All sessions up to
    <today>; after that, only World of Agents sessions. Press Recount to include everything." Large totals read like
    "1.18B". The button stays. The hall's header shows the same total. (L14)
11. Press Recount again: the total doesn't grow (nothing counts twice; L14, L15).
12. `/reload-plugins`, then a new session: the same total and the same "All sessions up to <today>" line.
