The token ledger: how many tokens this PC has used, and what they would cost at API prices.

## New

- **"This PC" in the team pane.** Under the context and plan-limit lines, the pane counts every turn of every agent, the Lead's and each subagent's, per session: "This PC since 11 Nov 2026: 3.4M tokens in, 180K out, about $17.20 at API prices (13 Nov 2026)." The total is kept in the plugin's own store, so it survives reloads and new sessions. It holds numbers only: the token counts the API reports, per session and model.
- **The same total in the hall.** The hall's header shows "This PC: 3.6M tokens · about $17.20 at API prices" in Live, as soon as the hall answers, also when the pane has just started it. The pane sends it through a small fixed script in the plugin, which posts to the hall only after the hall proves it holds the token, like the hooks do. The hall keeps it in memory only.
- **Recount, when you ask.** A **Recount** button under the "This PC" line reads Claude Code's own transcripts on this PC through a small fixed script in the plugin, and every session in them counts, with the plugin or not. A session the pane already counted takes the transcript's exact count in place of its own, so nothing counts twice; a session whose transcript Claude Code has since deleted keeps its numbers, so the total never goes down. The line under the total says what it covers: "All sessions up to 13 Nov 2026; after that, only World of Agents sessions. Press Recount to include everything." The script prints only session ids and whole numbers, and the pane keeps them only when they are exactly that: nothing else of a transcript reaches the pane, the store or the hall.
- **Which hall you are looking at.** The hall's badge names its plugin version ("Forge Hall · v3.2.0"). Two installs on one PC share the hall's token file, so another install's hall used to pass for this one's; now the pane says "An older hall (before v3.2.0) is running. Close the sessions in your other projects." (from v3.2.0 on, with the version it states), shows no link to it and sends it no total. It never stops it: the hall goes when the session that started it ends.

## What it is and what it isn't

- **An estimate.** "About" means it. Claude Code writes the Lead's prompt cache for an hour and a subagent's for five minutes, which cost differently; the live count prices them that way because every response we measured did so, but the counts don't say. Recount uses each transcript's own split. Fast mode isn't priced separately, and the prices are the API's as of 13 Nov 2026. On a Pro or Max plan it isn't money you spent. It is the number to have when you compare a subscription with paying per token.
- **Only where the plugin runs**, until you press Recount; then every Claude Code session on this PC up to that day. A session where a turn may still be running (anything in its last 10 minutes, or a tool call waiting) keeps its live count until a later Recount. claude.ai, the phone and other PCs share your plan and are never counted. claude.ai/settings/usage is the full picture, and the pane's plan-limit lines come from the same place.
- **"This PC"**, because a plugin can't tell which account is logged in.

## Updating from v3.1.0

In a terminal. Adding the marketplace again with a new tag is refused, and removing it uninstalls the plugin, so install it again in each project that had it:

```bash
claude plugin marketplace remove world-of-agents
claude plugin marketplace add kremendev/world-of-agents#v3.2.0
claude plugin install world-of-agents@world-of-agents --scope local   # in each project folder
```

Then run `claude plugin list`: no `world-of-agents` entry may say `Scope: user`. The setup's template hasn't changed, so `/world-of-agents:setup-project` says "Already set up". Until every project you use runs v3.2.0, the pane may name an older hall: close the sessions in the projects that still run the old one.

Claude Code 2.1.312 or later and Node.js 20.19 or later, as in v3.1.0. Setup and the full security notes are in the [README](https://github.com/kremendev/world-of-agents/blob/v3.2.0/README.md).
