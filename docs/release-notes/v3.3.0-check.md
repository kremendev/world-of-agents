## Before you start

1. In the repo, on `v3-next` at the v3.3.0 commit: `npm run dev:refresh`, stop any hall on 4319 (v3.1.0's checklist,
   step 2). `woa-m2-test` needs a `check` script for gates: add `"check": "node check.js"` to its `package.json` (create

## Quality gates (3.3a)

2. In a new session in `woa-m2-test`, type `/world-of-agents:setup-gates`: it explains what gates do and what they cost, and
   says they are off. Nothing changed (`git status` shows nothing new under `.claude/`, which git ignores anyway).
3. Type `/world-of-agents:setup-gates-write`: "Turned on". Start a new session (gates apply from the next one). The pane
   says "Quality gates: on."
4. Switch the mode selector to Accept edits and send any prompt: the pane warns "Quality gates: npm run check runs after
   each dev's task without asking." Back to Manual: the warning goes.
5. Type: **Have the Backend dev fix the bug in hello.js.** If the dev's first fix doesn't pass, the pane says "Quality
   gate: Backend dev's check failed, retry 1 of 3." and the hall keeps the Backend dev working (its card stays In progress).
   When the check passes the card goes Done. (This is the one thing the terminal runs couldn't show: there, the dev passed
   the first time.)
6. To see a failure end: make `check.js` fail always (`process.exit(1)`), ask for a small change to hello.js: after the
   third retry the dev stops, the hall shows it in error, the card stays open, and the Lead reports it to you.
7. `/world-of-agents:setup-gates-off`: "Turned off". A new session: no gates line in the pane, and a dev's stop runs no check.
