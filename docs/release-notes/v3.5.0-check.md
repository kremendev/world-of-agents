# v3.5.0 desktop check

For Dima, before the `v3.5.0` tag. Only what needs you: the desktop app and the pages you see. Everything else was
proven without you (docs/v3.5-plan.md, each part's notes). Each step says what you should see and which part it proves.
Anything that doesn't match: stop there and note the step number.

## Before you start

1. In the repo: `git switch --detach ed42ec6`, then `npm run dev:refresh`. Stop any hall on 4319 (in PowerShell:
   `Get-NetTCPConnection -LocalPort 4319 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess }`).
   Close all other sessions. Open `woa-m2-test` in the Code tab, one new session, Manual, `/reload-plugins`.

## The hall runs on its own (3.5b)

2. Type **hi**. The pane says "Hall: running"; press **Open hall** and leave the page open.
3. Close that session (not the app). The hall page stays **Live**: no "Hall offline". Wait a minute; still Live. (In
   v3.4.0 it went with its session.)
4. Open a new session in `woa-m2-test` and type **hi**. The pane says "Hall: running" without "Hall: starting", and
   the page shows the new run with no "Hall restarted": the same hall served both sessions.
5. `/reload-plugins`, then type **hi** again: the page stays Live, still no "Hall restarted".
6. Quit the desktop app completely, then press F5 on the hall page. Note what it says: **Live** (the hall outlived the
   app) or **Hall offline** (quitting the app ends it). Either is fine; I only document which. Open the app again.
7. The idle stop: one session in `woa-m2-test`, type **hi** (the hall runs again if step 6 ended it). Close the hall
   page and type nothing for 31 minutes. Then the PowerShell line from step 1 without the `Stop-Process` part,
   `Get-NetTCPConnection -LocalPort 4319 -State Listen`, finds nothing. Type **hi**: "Hall: running" again, and
   **Open hall** opens a hall that says nothing of before.

   shows A's run as it was (the Lead's first answer to you is back in the feed, once) and then the new prompt, with no
   "Hall restarted". Press F5: the same.
9. With Narrator on, repeat the switch back of step 8: Narrator reads nothing old aloud when A's run comes back, only
   what is new.
