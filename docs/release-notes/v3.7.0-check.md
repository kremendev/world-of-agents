## Found on the way, for Dima

Claude Code 2.1.325, which updated itself on this PC on 15 Nov, prints two new warnings at the start of every session in
a set-up project. Neither stops anything today. Both are decisions for Dima, so neither is changed here:

- **The main agent.** "Plugin "world-of-agents" set this session's agent. That will stop working in a future release:
  set `agent` in your own settings or pass --agent." This is `plugin/settings.json`, which makes the Lead the main
  agent.
  - **The way out it names:** `agent` in the project's settings, which the setup could write (a new template version).
- **The template's Write rule.** "Permission deny rule (.claude\settings.local.json): Write(~/.world-of-agents/\*\*) is
  not matched by file permission checks — only Edit(path) rules are." The template's `Edit(~/.world-of-agents/**)` deny
  already covers every editing tool, by Claude Code's own words, and the guard denies those writes for every agent
  anyway.
  - **Dropping the `Write` rule** would be a new template version too.
