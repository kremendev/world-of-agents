For Dima, before the `v3.7.0` tag, after v3.6.0's check and tag. Only what needs you: the desktop app, the Notes tab next
to your mockup, Narrator and two small real runs. Everything else was proven without you (docs/v3.7-plan.md, each part's
notes; the Notes tab in Edge on a throwaway hall, keyboard only). Each step says what you should see and which part it
proves. Anything that doesn't match: stop there and note the step number.

## Before you start

1. In the repo: `git switch --detach dc6c664`, then `npm run dev:refresh`. Stop any hall on 4319 (in PowerShell:
   `Get-NetTCPConnection -LocalPort 4319 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess }`).
   Close all other sessions. Open `woa-m2-test` in the Code tab, one new session, Manual, `/reload-plugins`. The team
   plugin must be installed there (it is since v3.4.0's check; `claude plugin list` shows `woa-team@woa-local`).

## A proposal (3.7b)

2. Open the hall. Type: **Have the Frontend dev add a one-line comment at the top of counter.js that says what the
   file does. No review needed. If it learns where the counter's code lives, it may propose a note.** When the Frontend
   dev finishes, its report's last line is `Proposed note: …`, and the feed shows "Frontend dev proposed a note to keep.
   It waits for you on the Team page." (If it proposes none, ask once more in the same words; a guild lead decides
   whether something is worth keeping.)

## The Notes tab (3.7d) and approving (3.7c)

3. Press **Open Team page** in the pane and open the link, then the **Notes** tab. Put it next to your mockup's page 6:
   "Waiting for you · 1", the Frontend dev's note whole, its flags if any, "Nothing is written until you approve. If you
   approve, the Frontend dev reads this at the start of its next runs.", Approve and Reject.
4. With Narrator on, Tab to **Approve** and press Enter. Narrator reads "Approved the Frontend dev's note." The pane
   shows "Note approved for the Frontend dev" within 20 s. The note is now under "Kept · 1", as on your mockup's page 1.
5. `/reload-plugins`, then type: **Ask the Frontend dev where the counter's code lives, from what it already knows. It
   runs nothing and reads no file.** Its answer names what the note says: the note reached it as a preloaded skill.
