Small changes to the HUD after v4.0.0: a shorter top bar on phones, a calmer Follow button, and a closer picture in the README.

## Changes

- **A shorter Demo top bar on phones.** Under 48rem the Demo's top bar took four rows (10.81rem at 320 to 400 px wide). Now it takes the title's row and one row of buttons, 7.34rem with the run line under them:
  - "Back to live" and "Go live" sit at the end of the title's row, as the word "Live", still named in full for screen readers.
  - Rooms and Activity are icons (a floor plan, and a list with its unread count on the corner), each named as before.
  - Play and Pause are one button, the one that works now.
  - Before the run has its tasks, **New task** opens the task input in place of the buttons; Esc, its close button or sending closes it, and the focus goes back to New task.

  Every control is still there, at least 2.5rem, and the focus moves in the order you see. Wider than a phone, nothing changes. Rooms and Activity are icons in Live on a phone too, so that bar is one row as well.

- **Follow looks like an ordinary button while it is off.** It was orange, the colour of a pressed button, before you pressed it. Now it says "Follow" in the plain style, and "Following" in orange while the camera follows.
- **The README's second picture** shows the Reviewer large, reading at its Library desk.

## Not in this release

The raised hand an agent shows while it needs you is still the 4.0.0 marker over its name tag. The raised-hand animation for the figures waits for its files and moves to 4.0.2.

## Updating from v4.0.0 or v3.10.0

In a terminal (Git Bash):

```bash
claude plugin marketplace remove world-of-agents
claude plugin marketplace add kremendev/world-of-agents#v4.0.1
claude plugin install world-of-agents@world-of-agents --scope local   # in each project folder
```

then `/reload-plugins` in a session that is already open. Your projects' teams, notes, library and settings stay as they are, and so do the pane's "This PC" count and its mute. A hall from 3.5.0 on that is still running is stopped and replaced by the new one at your next message.

Claude Code 2.1.312 or later, Node.js 20.19 or later, and a browser with WebGL 2 for the keep, as in v4.0.0. Setup and the full security notes are in the [README](https://github.com/kremendev/world-of-agents/blob/v4.0.1/README.md).
