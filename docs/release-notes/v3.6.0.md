The Team page: specialists of your own, switched on and off as you like, and a refresh for your team after an update.

## New

- **The Team page.** **Change skills** in the pane opens the hall's Team page through the same one-time link as before. It is its own view now, not a drawer: the hall keeps running behind it, and **Back to the hall** brings it back as it was. A search box at the top finds specialists by name, role or skill, and skills by name or what they're for; each tab counts what it found. A status line says what each change did.
- **Specialists of your own.** **+ Add specialist** asks for a name, a guild, one line of what it does (its guild lead reads that line to decide when to call it), what it may do, and up to 5 skills. It always runs on Sonnet. It gets its id from its guild and its name, shown as you type: "Form builder" in the Frontend guild is `woa-team:frontend-form-builder`, so the name and the guild stay as they are once it exists. Change its line, what it may do and its skills; delete it, and its skills stay in the team. At most 5 specialists per guild.
- **What it may do: three presets.** **Reads only** (it reads and searches files, then reports), **Edits files** (it also changes files, and runs no commands) and **Edits files and runs checks** (it also has a shell; the project setup lets only `npm test` and `npm run check` run without asking, and anything else asks you). The Design guild runs no commands, so it gets the first two only. A new specialist starts on Reads only.
- **On and off.** Switch a specialist off and its guild lead can't start it: the guard denies the start and says the specialist is switched off. Its file stays as it was, so switching it back on counts at once, with no reload.
- **Undo.** Take a skill off a specialist with **×**, and the status line offers Undo.
- **A refresh after an update.** When your team's specialist files come from an older plugin, the pane says "Your team's specialist files are from an older plugin. Type /world-of-agents:setup-team-write to refresh them." That command now refreshes an existing team: it writes again only the files the plugin makes from your team, and keeps every specialist, skill, switch and text of yours. It stops, changing nothing, if a skill file was edited by hand.
- **A new look for the page you work in.** The Team page has a plainer, modern look with the Inter font, from one set of colours the rest of the page will move to after v3.7. The hall stays pixel art.

## Under the hood

- `~/.world-of-agents/team/team.json` is version 2: each specialist has a preset and an on switch, and the file records which version of the generated text wrote the team's files. A version 1 file (v3.4.0 and v3.5.0) reads as version 2, every specialist keeping exactly the tools it had: readers stay readers, Design editors edit, and the other editors keep their shell. The next save writes it as version 2.
- The pane runs one more fixed script at session start, `hooks/team-check.mjs`, and reads only its exit code.
- A test pins the generated agent and skill text to its version number, so a change to the text can't ship without the pane noticing teams that are older.

## Updating from v3.5.0

In a terminal (Git Bash):

```bash
claude plugin marketplace remove world-of-agents
claude plugin marketplace add kremendev/world-of-agents#v3.6.0
claude plugin install world-of-agents@world-of-agents --scope local   # in each project folder
```

The pane replaces the v3.5.0 hall on its own: v3.5.0 is the first hall a newer plugin can ask to stop. Then the pane says your team's specialist files are from an older plugin: type `/world-of-agents:setup-team-write`, then `/reload-plugins`. Your specialists, skills and assignments stay exactly as they are.

A new or changed specialist, or a changed skill, counts from the next `/reload-plugins` or a new session, as skills did in v3.4.0. Switching a specialist off or on counts at once.

Claude Code 2.1.312 or later and Node.js 20.19 or later, as in v3.5.0. Setup and the full security notes are in the [README](https://github.com/kremendev/world-of-agents/blob/v3.6.0/README.md).
