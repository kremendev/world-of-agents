# World of Agents team pane

The World of Agents mod answers this command itself and opens the team pane, so this text normally never reaches you.
If you are reading it, the mod did not answer: it isn't loaded in this session. Run nothing and change nothing. Tell
the user, in one sentence, that the team pane could not be opened because the World of Agents mod isn't loaded here,
and that they can check the plugin is enabled for this project and then run /reload-plugins.
