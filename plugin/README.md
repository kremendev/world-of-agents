The World of Agents plugin for Claude Code: five agents (Lead/PM, Designer, Frontend dev, Backend dev, Reviewer) and the hooks that report what each one does to the Forge Hall, a small server on 127.0.0.1.
It starts with `woa` and needs the hall running to show anything. Setup, security notes and known limits are in the [main README](../README.md).

Two parts answer back. The guard hook (`hooks/guard.mjs`) can only deny: an agent start outside the team's table, or a shell command that names a `.env` file. `/world-of-agents:setup-project` shows, and `/world-of-agents:setup-project-write` writes, Manual mode, subagent depth 2 and a safe-command list into the project's `.claude/settings.local.json`, copied from `skills/setup-project/template.json` by a script Claude Code runs. You type both; the model can't start either.

**Requires Claude Code 2.1.295 or later, and Node.js 20.19 or later on PATH.** The guard fails closed: without Node, every agent start and every Bash or PowerShell command in a project with the plugin is blocked with `hook error: [node ${CLAUDE_PLUGIN_ROOT}/hooks/guard.mjs]: failed; blocking because onFailure is "block" Error occurred while executing hook command: Executable not found in $PATH: "node"`. Install Node, or turn the plugin off for that project: `claude plugin disable world-of-agents@world-of-agents --scope local` in the project folder, or switch it off in the desktop app under Customize, then Plugins.
